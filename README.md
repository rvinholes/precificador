# Precificador Universal

Aplicativo web para calcular o preco de venda de qualquer produto ou servico, com custos detalhados de materiais e mao de obra.

## Como usar

1. Em **Materiais**, informe: quantidade usada, unidade de uso, custo da embalagem, quantidade na embalagem e unidade de compra.
2. Em **Mao de obra**, informe funcao, quantidade e valor por unidade.
3. Em **Custos adicionais**, inclua embalagem, frete, taxas, etc.
4. Ajuste os **Parametros** (encargos, overhead, impostos, margem, comissao, financeiro).
5. O **preco de venda** aparece automaticamente no resumo.

## Funcionalidades

- Conversao automatica de unidades (mg/g/kg/ton e mL/L/m3)
- Calculo de custo real por unidade
- Perda/desperdicio por material
- Encargos, overhead, impostos, margem, comissao e financeiro configuraveis
- Salvamento local no navegador
- Exportacao em CSV
- Impressao / PDF
- 4 exemplos prontos
